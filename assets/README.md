# Futlive Assets

Estrutura oficial dos assets visuais.

- `players/team-1/` — 32 frames do uniforme/time azul atual.
- `players/team-2/` — 32 frames do uniforme/time vermelho atual.
- `players/team-3/` a `team-6/` — reservados para futuros times/skins.
- `ball/` — sprites e animações da bola.
- `goals/` — traves/gols.
- `maps/` — campos/mapas.

Não subir PNGs soltos na raiz do repositório. Quando entrar um pacote novo, ele deve ir direto para a pasta do tipo correto. O inventário fica em `config/assets.json`.
